DroneVision на Windows 10/11
============================

Установка (один раз) - три шага, ничего набирать не нужно
---------------------------------------------------------
1. Скачайте программу: на странице проекта в GitHub нажмите зелёную кнопку
   «Code» -> «Download ZIP».
2. Распакуйте архив: правой кнопкой по файлу -> «Извлечь всё…». Лучше в папку
   с простым путём, например C:\DroneVision. Не запускайте программу прямо
   из архива.
3. Дважды щёлкните DroneVision.bat в распакованной папке.
   Если Windows покажет «Система Windows защитила ваш компьютер» - нажмите
   «Подробнее» -> «Выполнить в любом случае».

Первый запуск занимает 2-5 минут и требует интернета (скачивается около
300 МБ). Программа всё ставит сама: Python 3.12, его пакеты и программы для
чтения видео. Устанавливать Python заранее не нужно, права администратора не
нужны, в систему ничего не добавляется. Если Python уже стоит - он не
мешает и не изменяется. Дальше интернет не нужен, запуск занимает секунды.

Обновление: скачайте ZIP заново и распакуйте в новую папку. Папки с данными
и результатами лежат отдельно и не затрагиваются.
Удаление: просто удалите папку программы.

Работа
------
- DroneVision.bat открывает чёрное окно и страницу http://127.0.0.1:8765 в браузере.
  Чёрное окно должно оставаться открытым, пока вы работаете. Закрыли окно —
  программа остановлена.
- Видео выбирается кнопкой «Выбрать…» в разделе «Файлы». Рядом с видео
  должны лежать:
    DJI_XXXX.SRT          - субтитры с телеметрией (та же папка, что и видео);
    FlightRecords\*.txt   - полётные логи DJI (в папке видео или до пяти уровней выше).
  Лог подбирается автоматически по GPS.
- Результаты сохраняются в «Папку проекта»; по умолчанию это
  DroneVision-project рядом с видео.
- Видео и логи никуда не отправляются: вся обработка идёт на этом компьютере.
- Сессия сохраняется сама: при следующем запуске откроются то же видео,
  отмеченные кадры и интервалы, настройки, разметка и последние результаты.
  Кнопки вверху страницы: «Сохранить в файл…» (файл .dvsession.json, по
  умолчанию в папке проекта), «Открыть из файла…», «Новая сессия».
  Изображения результатов хранятся в папке проекта: если её удалить или
  перенести, результаты нужно будет построить заново.

Папка с данными
---------------
При первом запуске программа попросит указать папку с данными (кнопка
«Указать папку с данными…» вверху страницы). Она сама найдёт в этой папке все
видео с телеметрией и покажет их списком; папка запоминается. Если при
следующем запуске папка недоступна (например, не подключён внешний диск),
программа скажет об этом и предложит подключить диск и нажать «Проверить
снова» или указать папку заново. Кнопки «Обновить» и «Сменить папку…»
находятся над списком.

Что должно быть в папке (в любых подпапках, до 7 уровней вложенности):
  - видео:  DJI_XXXX.MP4 (или MOV), к имени можно дописывать пояснение;
  - SRT:    файл с тем же именем или тем же номером DJI_XXXX.SRT - рядом с
            видео или в любой другой подпапке;
  - логи:   DJIFlightRecord_*.txt (или .json) - где угодно в этой папке.
Пары подбираются сами: SRT - по имени, полётный лог - по GPS и времени.
Если один номер DJI_XXXX встречается в разных съёмках, держите SRT рядом со
своим видео (в той же папке или в папке той же съёмки).
Видео без SRT или без логов показаны серым с пояснением, чего не хватает.
Папка с данными не обязательна: любое видео можно открыть кнопкой «Выбрать…».

Если что-то не работает
-----------------------
- Запустите DroneVision-check.bat: он покажет, чего не хватает, и докачает
  недостающие программы в папку bin. Снимок этого окна - лучшее, что можно
  прислать разработчику.
- Первый запуск оборвался (пропал интернет, закрыли окно) - просто запустите
  DroneVision.bat ещё раз, он продолжит с того же места.
- Окно сообщает, что окружение Python подготовить не удалось - обычно это
  сеть организации, которая не пускает к github.com или pypi.org. Попробуйте
  другую сеть (например, раздать интернет с телефона) или установите
  Python 3.12 (64-bit) с https://www.python.org/downloads/windows/ с галочкой
  «Add python.exe to PATH» и запустите DroneVision.bat снова.
- «Порт 8765 занят» - программа уже запущена в другом окне; просто откройте
  http://127.0.0.1:8765.
- «Не найден DJI_XXXX.SRT» - положите SRT-файл рядом с видео.
- Кнопки «Суша», «Берег», строка «Берег» под видео и «Подобрать курс по берегу»
  работают для районов, для которых в папке maps есть вырезка береговой линии
  (coast_osm_*.shp; Белое море и районы съёмок набора уже лежат там). Для нового
  района: python -m dronevision coastline --at ШИРОТА ДОЛГОТА (нужен интернет,
  один раз скачивается ~1 ГБ в папку DroneData\maps\osm-planet).
- Антивирус может удалить файлы из папки bin (ffmpeg.exe, ffprobe.exe,
  dji-log.exe). Верните их из карантина или запустите DroneVision-check.bat.
- Папку программы можно переносить. Если после переноса программа не
  запускается, удалите папку .venv и снова запустите DroneVision.bat.
